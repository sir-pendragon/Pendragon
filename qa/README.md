# 最新版の回帰テスト

Node.js 24.15以降の24系で、リポジトリのルートから順に実行します。

```sh
npm ci --prefix qa --no-audit --no-fund
node qa/audit.cjs
```

49項目で、1,974条件の移動、17種類の敵とツチノコ、作戦、補給食、キャンプ、催事、改造、スポンサー、全国クリア、決算、v4/v5/v6セーブ、リセットなどを確認します。jsdom上で実コードを実行し、各テストの保存領域を独立させています。

## 公開の前に（版の識別子）

`index.html` を変えたら、公開（push）の前に必ず次を実行します。自動更新は、実行中のコードの `APP_V` と、配信中の `index.html` の `APP_V` を比べて更新を検知します。`APP_V` は内容から計算する値なので、更新し忘れると、古いタブが更新を検知できません。

```sh
node qa/stamp.cjs          # APP_V を更新
node qa/stamp.cjs --check  # 古ければ失敗終了（何も書き換えない）
```

監査テスト（`node qa/audit.cjs`）にも、`APP_V` が最新かの確認が入っています。

音声とタイマーはテスト用に置き換えます。実機のタッチ操作や聴感は別に確認してください。結果と制限は `docs/debug-latest.md` に記載しています。
