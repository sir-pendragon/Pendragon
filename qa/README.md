# ゲームの回帰テスト

Node.js 24.15以降の24系を推奨します。ゲーム自体はビルドやnpmを必要としません。

リポジトリのルートで次を順に実行します。

```sh
npm ci --prefix qa --no-audit --no-fund
node qa/audit.cjs
```

32項目で起動、戦闘、キャンプ、購入・装備、保存・復元、リセット、年末、全国制覇後の進行を検証します。実コードをjsdom上で実行し、テストごとに独立した保存領域を使います。実ブラウザのセーブには触れません。

音声の再生とアニメーションタイマーは置き換えています。スマートフォン実機や聴感の検証を代替するものではありません。実装と検証範囲は `docs/debug-report.md` を参照してください。
