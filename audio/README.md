# audio/ に置くファイル（mp3）
置いたファイル名で自動的に鳴ります。無いファイルは無音です。

| ファイル名 | 用途 | 目安 |
|---|---|---|
| bgm_main.mp3 | 牧歌的なメインBGM（地図・キャンプ画面） | ループ可能、1〜2分 |
| bgm_battle.mp3 | バトルBGM | ループ可能、1〜2分 |
| se_encounter.mp3 | 敵に遭遇 | 0.5〜1.5秒 |
| se_hit.mp3 | ダメージを与えた | 0.2〜0.6秒 |
| se_damage.mp3 | ダメージを受けた | 0.2〜0.6秒 |
| se_win.mp3 | 敵を倒した | 0.8〜2秒 |
| se_photo.mp3 | 撮影した（達成感のある音） | 1〜2.5秒 |

形式: mp3（44.1kHz、128kbps程度）。BGMは1曲1MB前後に収める。
| se_turn.mp3 | 新しいターンの収支ポップアップ（自転車のベル「りりん」） | 1〜1.5秒 |
