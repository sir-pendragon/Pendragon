## 仕様として判断が必要な点

自転車と太タイヤに設定された「悪路（rough）」の値は、現状の戦闘計算から参照されていません。悪路の県では敵の種類が変わりますが、各敵が参照する能力は登坂・巡航・耐候です。このため、太タイヤの「悪路+2」は現在の計算では効果がありません。

これは能力と敵の対応付けに関わるゲーム設計の問題として記録しました。敵の参照能力やゲームバランスの変更は今回の修正版に含めていません。
