設定

この画面は自分専用です。写真を削除するには、下の「GitHubの合言葉(トークン)」が必要です。トークンが無ければ、一覧を見るだけで何も変更できません。

GitHubの合言葉(トークン)

このブラウザの中にだけ保存します(サイトの公開ファイルには入りません)。共用のパソコンでは保存しないでください。

トークンの作り方
  1. GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access は「Only select repositories」で Pendragon だけを選ぶ
  3. Permissions → Repository permissions → Contents を「Read and write」にする(他は不要)
  4. 有効期限は短めに設定し、作った文字列をここに貼り付ける

掲載済みの写真

削除したい写真を押して選び(赤くなります)、「選んだ写真を削除」を押してください。
