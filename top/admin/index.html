設定

この画面は、Cloudflare Access で守られた自分専用の画面です。

写真を追加

写真を選ぶと、ブラウザの中で縮小します(公開用 長辺1600px・一覧用 360px)。このとき撮影場所(GPS)などの情報は取り除かれます。1回に10枚までです。JPG・PNG・WebP が使えます(iPhone の HEIC は、多くのパソコンのブラウザで開けないため、JPG に変換してください)。

追加前に、人の顔・表札・ナンバーなどの個人情報が写っていないか確認してください。同じ写真は自動で外れます。写真を押すと「追加する/しない」が切り替わり、左上の「×」で一覧から取り除けます。

掲載済みの写真

削除したい写真を押して選び(赤くなります)、「選んだ写真を削除」を押してください。
